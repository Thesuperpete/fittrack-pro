คู่มือประเภทเซ็ต (Set Types Guide)

GYMBRO GUIDE

ความหมายของ N, W, D, SS, F & เทคนิค Super Set

N
Normal (Working Set) เซ็ตหลัก

เซ็ตทำงานจริงที่ใช้น้ำหนักเป้าหมาย (RPE 8–9) เพื่อสร้างมวลกล้ามเนื้อ (Hypertrophy) นับ Volume จริงในสถิติ

W
Warmup (เซ็ตวอร์ม) เตรียมพร้อม

ใช้น้ำหนักเบา (40–60% ของน้ำหนักจริง) เพื่อปรับความคุ้นชินของข้อต่อและระบบประสาท ไม่เล่นจนหมดแรง และไม่นับ Volume หนักในกราฟ

D
Drop Set (ลดน้ำหนักทันที) ขยี้กล้ามเนื้อ

พอยกเซ็ตหลักจนหมดแรง ให้ลดน้ำหนักลง 20–30% ทันที แล้วยกต่อจนหมดแรงโดยไม่พัก เพื่อปั๊มเลือดเข้ากล้ามเนื้อถึงขีดสุด

SS
Super Set (เซ็ตจับคู่ต่อเนื่อง) 2 ท่าติดกัน

เล่น 2 ท่าติดต่อกันโดยไม่มีเวลาพักระหว่างท่า (พักหลังจบทั้ง 2 ท่า) ประหยัดเวลา 50% และเพิ่มความหนาแน่นในการฝึก

F
Failure (ยกจนหมดแรง 100%) RPE 10

ดันจนไม่สามารถยกขึ้นได้อีกแม้แต่ครั้งเดียว (RPE 10) นิยมใช้ในเซ็ตสุดท้ายของท่าเพื่อปลุกเส้นใยกล้ามเนื้อทั้งหมด

หลักการตั้ง & จับคู่ Super Set (SS) ให้ได้ผลสูงสุด:

1. 🏆 Antagonist Pairs (กล้ามเนื้อฝั่งตรงข้าม - แนะนำที่สุด): จับคู่มัดที่ทำงานตรงข้ามกัน เช่น Biceps (หน้าแขน) + Triceps (หลังแขน) หรือ Chest (อก) + Back (หลัง)
➔ ข้อดี: ขณะที่มัดหนึ่งทำงาน มัดตรงข้ามจะได้พักผ่อนและยืดตัว ทำให้แรงไม่ตกและประหยัดเวลาได้ครึ่งต่อครึ่ง!
2. ⚡ Compound + Isolation (ขยี้มัดเดิม): เล่นท่าเน้นแรงตามด้วยท่าบีบโฟกัส เช่น Incline DB Press (อกบน) + Pec Deck Fly (หนีบอก)
➔ ข้อดี: รีดเค้นเส้นใยกล้ามเนื้อจนถึงขีดสุด เหมาะสำหรับมัดที่พัฒนาช้า
⚠️ ข้อควรระวังสำคัญ (Golden Rule): ห้ามทำ SS กับท่า Heavy Compound ท่าใหญ่พร้อมกัน (เช่น ห้ามทำ Barbell Squat คู่ Deadlift) เพราะจะทำให้ระบบประสาทส่วนกลาง (CNS) ล้าเกินไปและฟอร์มพัง ให้เน้นทำกับท่า Isolation หรือมัดเล็กช่วงท้ายเซสชัน
